# Custom robots.txt — allows AI crawlers for AEO (Answer Engine Optimization)
# Cloudflare's "AI Scrapers and Crawlers" toggle generates a managed robots.txt
# that blocks all AI bots. This custom file overrides it so AI answer engines
# (ChatGPT, Perplexity, Claude, Google AI Overviews) can read and cite our content.
# AI training is still blocked via the Content-Signal header (ai-train=no).

User-agent: *
Allow: /
Disallow: /api
Content-Signal: search=yes, ai-input=yes, ai-train=no, use=reference

# /api returns 402 (x402 payment) and /api/indexnow, /api/mcp return 405 (GET not
# allowed). These are non-404 4xx responses that GSC flags as "Blocked due to
# other 4xx issue." Disallow /api for general crawlers (Googlebot) to prevent
# the warning. AI agents below have their own Allow: / sections so they can
# still discover the API.

# /operator/* 308-redirects to signalaf.com/user/* — allow crawling so
# Google can discover the redirect and pass link equity to the canonical profile.
# (Previously disallowed, which blocked Google from seeing the redirect.)

# Explicitly allow AI answer-engine crawlers (AEO)
